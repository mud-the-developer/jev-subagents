# SoL-Pi regression fixture

Standalone SoL-Pi is independent of this extension. `jev-subagents` does not activate, configure or duplicate its hooks. A Sol model used through an explicit fixed ordinary profile is not SoL-Pi harness activation.

The source retains a pinned upstream fixture for offline regression continuity. See [its README](../test/fixtures/sol-pi/README.md) and [NVIDIA MIT license](../test/fixtures/sol-pi/LICENSE); keep those files and SPDX notices unmodified. This fixture does not certify a live model, native user approval, costs or production isolation. It never restores execution authority from stored data.

Use [ordinary usage](usage.md) and the existing explicit approval contracts. Do not treat historical Goal/context/SoL-Pi integration modules as additional public tool registrations.
